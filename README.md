# タイピング練習ゲーム（HSP）

このゲームは、HSP（Hot Soup Processor）で制作したタイピング練習ゲームです。  
ただローマ字を素早く打つだけでなく、「変換操作」を含んだタイピング力を養うことを目的としています。

---

## 🎮 特徴

- **変換ありのタイピング練習**：表示された日本語の文章を正しく変換して入力します
- **好きな文章を使用可能**：任意のテキストファイルを読み込んでオリジナル問題を作成できます
- **詳細な記録**：各問題ごとの成績や記録を確認でき、復習にも役立ちます

---

## 🖥 開発情報

- 使用言語：HSP（Hot Soup Processor）
- 実行環境：Windows（HSP環境が必要）
- 開発環境：HSPエディタ + 実行形式（`.hsp`）

---

## 🔧 実行方法

1. [HSP公式サイト](https://hsp.tv/) からHSPをインストール
2. このリポジトリをクローンまたはZIPでダウンロード
3. `main.hsp` をHSPエディタで開き、「実行」ボタンを押す

---

## ⚙️ 保存フォルダと設定

設定の保存やアセットの変更時に `save/` フォルダが自動生成され、以下のファイルが使用されます：

| ファイル名 | 内容 |
|------------|------|
| `option.txt` | 各種設定情報（例：難易度、表示切り替えなど） |
| `Assets.txt` | 使用する問題文の一覧（1行＝1問） |

**カスタマイズ方法**：
- `Assets.txt` は使用アセットで「外部アセット」を選択した際に使用されるテキストファイルです
- 各行が1問として扱われます
- **先頭に `//` がついた行はコメントとして扱われ、問題には出題されません**
